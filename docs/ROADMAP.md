# KalamAI roadmap

## Included in this MVP
- Public landing and legal template pages.
- Supabase email/password auth and protected learner area.
- Database migration with row-level policies and seeded levels/scenarios/vocabulary.
- Text AI chat with saved history.
- Structured Arabic correction and correction history.
- Saved vocabulary, activity counts, profile settings, admin scenario creation, account deletion endpoint.

## Next phases
- Audio recording and speech-to-text with explicit consent; no raw recordings are collected now.
- Realtime voice and human language exchange.
- Placement test and automatic level progression after a reviewed rubric is available.
- Lesson CMS, moderation tools, and instructor-reviewed evaluation dataset.
- End-to-end tests against a live Supabase project.
